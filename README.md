# Tell The Time! 🕐

A friendly, fun web app to help kids learn to read a clock — six levels from
o'clock to reading any minute, with multiple-choice questions, a
drag-the-hands "set the clock" mode, stars, and spoken feedback.

Play it here: https://andbarker.github.io/Tell-the-time/

## Running locally

It's a static site with no build step. Just open `index.html` in a browser,
or serve the folder locally, e.g.:

```
python3 -m http.server
```

Progress is saved to the browser's local storage only.
